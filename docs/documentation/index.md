This section is for Modders and Developers who want to build on top of or integrate into **ObnoxiouslyNoxious's** Project Zomboid Mods. 
Documentation is split in to 2 distinct Categories:

| Category |Purpose| Integration |
|:---|:---|:---|
| **Framework** | Provides the core structure for your Mod to build on, allowing you to focus on the content rather than recreating the foundation.  | Register your Mod with the Framework, then build within the structure it provides.  |
| **API** | Offers a set of functions that lets your Mod interact with another Mod's features directly.| Check the API is loaded, then call its functions from your Mod's code. |
