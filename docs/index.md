-   ![Zombies Have Smokes](assets/img/mods/steam/zombies-have-smokes/preview.jpg){ .card-thumb }
    **[Zombies Have Smokes](mods/zombies-have-smokes.md)**
    <span class="pz-tag">B42</span><span class="pz-tag">SP/MP</span>

    Adds a configurable chance for Zombies to drop Cigarettes, Cigars, Lighters/Matches and Tobacco Products on Death.


-   ![Zombies Have Ammo](assets/img/mods/steam/zombies-have-ammo/preview.jpg){ .card-thumb }
    **[Zombies Have Ammo](mods/zombies-have-ammo.md)**
    <span class="pz-tag">B42</span><span class="pz-tag">SP/MP</span>

    Adds a configurable chance for Zombies to drop loose Ammo and Ammo Boxes on Death. Includes support for specific Firearms Mods.

-   ![Random Spawn Locations](assets/img/mods/steam/random-spawn-locations/preview.gif){ .card-thumb }
    **[Random Spawn Locations](mods/random-spawn-locations.md)**
    <span class="pz-tag">B42</span><span class="pz-tag">SP/MP</span>

    Every new Character spawns at a Random Location, drawn from 3,500+ verified Spawn Points across Knox Country, through a Random Spawn option on the 'Select Spawn Location' screen.

-   ![NPC Tiles](assets/img/mods/steam/npc-tiles/preview.gif){ .card-thumb }
    **[NPC Tiles](mods/npc-tiles.md)**
    <span class="pz-tag">B42</span><span class="pz-tag">SP/MP</span>

    Contains 532 placeable human NPC Tiles for Singleplayer and Multiplayer Admins. Includes an 'NPC Tile Placer' script and exposes a public API for Mod Integration.

-   ![Dynamic Challenges & Leaderboard](assets/img/mods/steam/daily-challenge-system/preview.gif){ .card-thumb }
    **[Dynamic Challenges & Leaderboard](mods/daily-challenge-system.md)**
    <span class="pz-tag">B42</span><span class="pz-tag">SP/MP</span>

    Every Rotation brings 7 new Challenges, drawn from over 100,000 definitions. Earn Currency, keep a Streak, spend it at the Vendors and climb the Leaderboard. Includes a public API for Mod Integration.

-   ![XP Ranks](assets/img/mods/steam/xp-ranks/preview.jpg){ .card-thumb }
    **[XP Ranks](mods/xp-ranks.md)**
    <span class="pz-tag">B42</span><span class="pz-tag">SP/MP</span>

    Every action in the game feeds a single Global Rank from 1 to 999, with Reward Boxes and a per-category Leaderboard. Includes a public API for Mod Integration.

-   ![DeadSplit](assets/img/mods/steam/deadsplit/preview.gif){ .card-thumb }
    **[DeadSplit](mods/deadsplit.md)**
    <span class="pz-tag">B42</span><span class="pz-tag">SP</span>

    An integrated Speedrun timer and AutoSplitter for Project Zomboid. Approved for Speedrun.com submissions. Covers every PZ Speedrun Category, with Run Export and Verification plus optional LiveSplit integration.

-   ![Livestock Traders](assets/img/mods/steam/livestock-traders/preview.gif){ .card-thumb }
    **[Livestock Traders](mods/livestock-traders.md)**
    <span class="pz-tag">B42</span><span class="pz-tag">SP/MP</span>

    Travelling Traders buy and sell nine Animal types from rotating or Admin-placed locations. Currency, listing limits, Selling and Rank requirements are all configurable.

-   ![Sidebar Drawer](assets/img/mods/steam/sidebar-drawer/preview.gif){ .card-thumb }
    **[Sidebar Drawer](mods/sidebar-drawer.md)**
    <span class="pz-tag">B42</span><span class="pz-tag">SP/MP</span>

    Moves compatible Mod Icons into a toggleable Drawer beside the vanilla Sidebar, with pages, a Vertical or Horizontal layout and a saved Icon order.

-   ![Auto-Drink Expanded](assets/img/mods/steam/auto-drink-expanded/preview.gif){ .card-thumb }
    **[Auto-Drink Expanded](mods/auto-drink-expanded.md)**
    <span class="pz-tag">B42</span><span class="pz-tag">SP/MP</span>

    Broadens the Auto-Drink functionality to enable Auto-Drinking from every safe Fluid type, including Milk, Juice, Soda and Alcohol.

-   ![Auto-Drunk](assets/img/mods/steam/auto-drunk/preview.jpg){ .card-thumb }
    **[Auto-Drunk](mods/auto-drunk.md)**
    <span class="pz-tag">B42</span><span class="pz-tag">SP/MP</span>

    Keeps a Character at a chosen Intoxication level, or drinks a set Alcohol dose on an interval, with Alcohol priority and per-Container controls.

-   ![Auto-Drink Revert](assets/img/mods/steam/auto-drink-revert/preview.gif){ .card-thumb }
    **[Auto-Drink Revert](mods/auto-drink-revert.md)**
    <span class="pz-tag">B42</span><span class="pz-tag">SP/MP</span>

    Restores the pre-42.19 Auto-Drink rule for mixed Containers where Water is the main Fluid, with Container Priority and per-Container controls.

-   ![GTA Menu Theme](assets/img/mods/steam/gta-menu-theme/preview.gif){ .card-thumb }
    **[GTA Menu Theme](mods/gta-menu-theme.md)**
    <span class="pz-tag">B42</span><span class="pz-tag">SP/MP</span>

    A Grand Theft Auto inspired Main Menu Theme with Menu Music, a layered Map-framed Parallax Slideshow, five Button Layouts and an optional GTA Logo. Requires Menu Theme Framework.

-   ![RDR Menu Theme](assets/img/mods/steam/rdr-menu-theme/preview.gif){ .card-thumb }
    **[RDR Menu Theme](mods/rdr-menu-theme.md)**
    <span class="pz-tag">B42</span><span class="pz-tag">SP/MP</span>

    A Red Dead Redemption inspired Main Menu Theme with Menu Music, looping Knox Country Videos, four Button Layouts and two Sub-Themes. Requires Menu Theme Framework.

-   ![Skill Master](assets/img/mods/steam/skill-master/preview.gif){ .card-thumb }
    **[Skill Master](mods/skill-master.md)**
    <span class="pz-tag">B42</span><span class="pz-tag">SP/MP</span>

    Unlocks magazine and research-gated recipes when a Skill reaches Level 10. Includes support to grant the matching Traits and includes support for recipes provided by other Mods.

-   ![GNC Starting Clothes](assets/img/mods/steam/gnc-starting-clothes/preview.gif){ .card-thumb }

-   ![AEBS Imperial & Metric Display](assets/img/mods/steam/aebs-converter/preview.jpg){ .card-thumb }

    <span class="pz-tag">B42</span><span class="pz-tag">SP/MP</span>

    Shows both Imperial and Metric temperature and wind speed in AEBS broadcasts, keeping the Server's native unit first.
